# MF Pulse - Real-time Mutual Fund Command Center

This is a complete frontend platform designed to monitor daily mutual fund performance, dynamic asset value simulations, and historical graphs.

## Features
- Dynamic realtime simulated NAV ticker increments.
- Advanced responsive visual analytics using Recharts.
- Sleek dark theme UI built using Tailwind CSS.

## Get Started
1. Run `npm install` inside the folder.
2. Launch with `npm run dev`.
